# À table — Android

Application Android de **À table**, le compagnon familial pour organiser les repas, les recettes, les réserves et les courses.

Cette version affiche l’application web existante dans une application Android installable.

## Ouvrir avec Android Studio

1. Décompresser le ZIP.
2. Ouvrir le dossier `a-table-android` dans Android Studio.
3. Accepter la synchronisation Gradle.
4. Brancher le téléphone avec le débogage USB activé.
5. Cliquer sur **Run**.

## Fonctions Android incluses

- navigation dans À table ;
- bouton Retour Android ;
- sélection de photos et fichiers ;
- autorisation caméra pour le scanner ;
- conservation de la session et des données web ;
- refus du trafic web non sécurisé.
